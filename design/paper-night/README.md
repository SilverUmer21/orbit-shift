# Paper Night design assets

Approved direction for the Orbit Shift remake (home, results, rewards and menu UI).
Gameplay, ring/gate formation, planets and the existing planes are out of scope for this pass.

- `svg/icons/` — folded-glyph UI icons on a 48 px grid.
- `svg/planes/` — exploratory paper-plane set (not adopted yet; the original ships stay).
- `app-icon-1024.png`, `app-icon-512.png` — store icon masters built on the game's Bloom Crown planet.
- `previews/` — renders of the Paper Night boards.

Tokens: Night 900 `#0A1F24`, Night 800 `#0E2A30`, Night 700 `#12363D`, Night 600 `#1A4A50`,
Paper `#FFF4DC`, Paper fold `#E9D6B0`, Mint `#A8F0CF` / `#5ED6A6` / `#2E9C80`, Gold `#FFC94D`,
Ember lip `#E0703C`, Coral `#FF6F61`. Type: Lilita One (display), Nunito 800/900 (UI).
