# Bundled fonts

Bundled locally so the game works offline (and inside the planned Android wrapper).

- `lilita-one-latin.woff2`: Lilita One by Juan Montoreano, SIL Open Font License 1.1.
- `nunito-latin-variable.woff2`: Nunito by Vernon Adams, Cyreal and Jacques Le Bailly, SIL Open Font License 1.1.

Both are the Latin subsets served by Google Fonts. License text: https://openfontlicense.org
